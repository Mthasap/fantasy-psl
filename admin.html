📌 How to find Player ID & Team ID on API-Football:
1. Go to dashboard.api-football.com → API → Endpoints → Players
2. Search by player name + league (288) + season (2025) — the id in the response is the Player ID
3. For Team ID: Endpoints → Teams → search by league 288 — the team.id field

📧 Email Setup — Resend.com
One-time setup required before emails will send
🔧 How to set up email sending (free, 5 min):

Step 1 — Go to resend.com → Create a free account (3,000 emails/month free)
Step 2 — In Resend dashboard: Domains → Add Domain → enter fantasypsl.co.za
Step 3 — Resend gives you 3 DNS records to add. Go to your domain registrar (where you bought fantasypsl.co.za) → DNS settings → add those 3 records
Step 4 — Back in Resend: API Keys → Create API Key → copy the key
Step 5 — In Vercel: Project → Settings → Environment Variables → Add:
   Name: RESEND_API_KEY  Value: paste your key here
Step 6 — Redeploy your Vercel project (push any small commit or click Redeploy)

✓ After this, emails will go out from noreply@fantasypsl.co.za to all users
⚠ RESEND_API_KEY is not configured — emails will not send until you complete the setup above

SEO Guide — Getting Found on Google

Each post you publish gets a unique URL at /news/[slug] that Google can index. Follow these tips to rank for PSL searches:

  • Use keywords like "PSL", "Betway Premiership", "Fantasy PSL" in your headline
  • Write at least 200 words in the article body — Google rewards longer content
  • Post within 1–2 hours of a match finishing for breaking news
  • Use the Tips category for transfer advice posts — these rank well for "PSL fantasy tips GW24" etc.
  • Add a cover image URL to get rich previews when shared on WhatsApp/Twitter

Posts are served with proper meta tags (title, description, og:image) so they preview correctly when shared.

PSL Squad Import
Fetch all registered PSL players from API-Football · approve new ones to add to your roster
How this works:
1. Click Fetch All Squads — pulls every registered player from API-Football for all 16 PSL clubs.
2. Players already in your roster show in green ✓ Known. New players not yet in your roster show in amber + New.
3. For each new player — verify position, set price, click Approve to add them to the DB.
4. Or click Approve All New to add everyone at once with default prices.
